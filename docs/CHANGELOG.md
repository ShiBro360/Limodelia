# Changelog

All notable changes to Limodelia CRM will be documented in this file.

## Version 0.1.0

Initial project structure.

### Added

- Created base PHP project structure for XAMPP.
- Added configuration folder.
- Added database planning folder.
- Added includes folder for shared bootstrap and layout orchestration.
- Added layouts folder with header, sidebar, topbar, and footer components.
- Added pages folder with initial module pages.
- Added API folder for future JSON endpoints.
- Added assets folder with CSS, JavaScript, and icons directories.
- Added uploads folder with trip and temporary upload directories.
- Added base entry files: `index.php`, `login.php`, and `logout.php`.
- Added centralized PDO configuration concept using UTF8MB4.
- Added unified layout approach for all CRM pages.
- Added initial project documentation folder.

### Documentation

- Added project architecture documentation.
- Added planned database documentation without SQL.
- Added UI system guide.
- Added development roadmap.
- Added changelog.
